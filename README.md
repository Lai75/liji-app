# 黎记（LiJi）

待办清单 + 习惯打卡 + 记账 + 数码库，一个单文件 Web App。

## 目录结构

```
shiji-app/
├── index.html          # 应用主文件（HTML + CSS + JS，无需构建）
├── chart.umd.min.js    # Chart.js 4.4.0（本地化，离线可用）
├── manifest.json       # PWA 清单（手机可“添加到主屏幕”）
├── sw.js               # Service Worker（离线缓存）
├── icon-192.png        # 应用图标
├── icon-512.png
└── README.md
```

## 本地运行

不需要安装任何依赖，两种方式任选：

**方式一：直接打开**
```bash
open index.html        # macOS
# 或双击 index.html
```

**方式二：本地起个静态服务器（推荐，某些浏览器对 file:// 下的 fetch/storage 有限制）**
```bash
cd shiji-app
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080
```

## 功能

- **待办清单**：分类清单、优先级、截止日期、子任务
- **习惯打卡**：每日/每周指定天打卡、连续天数统计、月度热力图
- **记账本**：收支记录、分类、月度汇总
- **数码库**：电子产品记录（名称、分类、品牌型号、购入日期/价格/渠道），按分类筛选，统计数量与总值
- **总览**：今日进度小票、支出结构饼图、近 7 天收支柱状图、数码资产总值、数据导出/导入备份
- **记账增强**：月度预算进度条（超支变红）、跨月搜索、分类月度小计、自定义分类
- **其他**：暗夜奢华主题（深炭黑 + 香槟金，默认深色，可切浅色）、账单/数码记录/任务标题可编辑、任务拖拽排序（桌面）与上移/下移按钮（触屏）、习惯年度热力图、数码持有天数与每日成本、删除二次确认

## 手机安装（PWA）

通过 HTTP 打开时（本地服务器或任意静态托管），浏览器菜单里选**“添加到主屏幕 / 安装应用”**即可像 App 一样全屏使用，安装后完全离线可用。直接双击 `index.html`（file://）打开时 PWA 功能自动跳过，其余功能不受影响。

## 数据存储说明

本地版本使用浏览器 `localStorage` 保存数据，单机、免安装、开箱即用。注意：

- 数据存在浏览器本地，清缓存/换浏览器/换设备会丢失或不同步——**总览页有「导出数据」按钮，建议定期备份成 JSON 文件**，换环境后用「导入数据」恢复
- 如果需要多设备同步，可以接入 Supabase / SQLite + 小后端，把 `loadKey` / `saveKey` 两个函数换成真正的 API 请求即可，其余业务逻辑不用动

## 技术栈

纯原生 HTML/CSS/JavaScript，图表使用 [Chart.js](https://www.chartjs.org/)（本地文件 `chart.umd.min.js`，离线可用；加载失败时总览自动降级为文本列表），无需 npm install。
